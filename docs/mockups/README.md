# Mockup del dashboard

`dashboard_mockup.html` es una referencia visual conceptual, no una interfaz de producción ni una implementación reutilizable del panel. La aplicación del MVP se implementa en Streamlit.

Las métricas de nuevos miembros, tasa de participación y top contributor son datos ilustrativos: no forman parte de `OutputBatch`. La fricción detectada también es una idea visual para una posible vista de alertas. Para datos reales, la interfaz debe limitarse al contrato del pipeline.

El HTML usa Tailwind y FontAwesome desde CDN; no debe desplegarse como sustituto de la aplicación Streamlit.
